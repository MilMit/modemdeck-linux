## 2. Key Concepts & Firmware Limitations

- **Configured Bands vs Serving Bands**: *Configured bands* (`CurrentBands`) are the bands the modem is allowed to use. *Serving band* is the actual frequency band of the tower cell currently serving your connection. Setting a band in `CurrentBands` does not guarantee coverage on that band.
- **Band Lock vs Cell Lock**: *Band Lock* uses ModemManager's standard `SetCurrentBands` API and is reversible without touching modem NV/EFS flash. *Cell Lock* (PCI + EARFCN) on Qualcomm/DW5821e requires writing NV/EFS files and resetting the modem, which can disable Carrier Aggregation; therefore ModemDeck keeps Cell Lock in safe **preview-only** mode unless explicitly verified.
- **Carrier Aggregation (CA)**: Selecting multiple bands (e.g. `B1+B3+B7`) only *permits* the modem to use them. Actual CA (2CA/3CA/4CA) is controlled by the tower/eNodeB and often activates only under active data load.
- **Unlocking Persistent Lock & Restoring Defaults**:
  1. Open **Network** tab → **Persistent Band Lock** → click **Unlock / Auto**.
  2. Or via CLI/recovery: remove `~/.config/modemdeck/persistent-locks.json` and run `mmcli -m 0 --set-current-bands=any`.

## 3. Dell DW5821e Snapdragon X20 LTE — Ubuntu Real-Hardware Test Plan

### Prerequisites
- Ubuntu 24.04+ with `ModemManager`, `NetworkManager`, and `pkexec` running.
- Dell DW5821e (T77W968) WWAN card installed.
- Two physical SIMs: **Irancell (43235)** and **SamanTel (43293)**.

### Step-by-Step Verification
1. **Install & Launch**:
   - Build & run: `cargo build --release && ./target/release/modemdeck` (or install `.deb` package).
   - Verify **Overview** tab shows live RSRP, RSRQ, RSSI, SNR with `Fresh` timestamp badge and `Extended signal metrics are not currently reported...` disappears automatically.
2. **Irancell SIM — 5-Minute Band Analyzer Test**:
   - Go to **Analyzer** tab → **Band Analyzer**.
   - Select **Radio-only Test** (or **Standard Test** with consent checked and 100 MB cap).
   - Set duration per band to **5 minutes (Default)**.
   - Select bands (e.g., `B1`, `B3`, `B7`, `B42`) and click **Start Band Scan**.
   - Confirm progress bar, elapsed/ETA, and cancellation/completion restore initial bands.
3. **Band Switching & Rollback Verification**:
   - Go to **Network** tab → **Band profiles** → select `B42 TD-LTE` → click **Apply profile**.
   - Wait 45 seconds *without* clicking **Keep this selection**: verify bands roll back and `profiles.json` did NOT save `B42 TD-LTE` as active.
4. **Persistent Lock & Reboot Recovery**:
   - Select `B1+B3+B7` → Apply → **Keep this selection**.
   - In **Persistent Band Lock**, select **Persistent Lock** + **Safe Lock** → **Save Lock Policy**.
   - Enable **Background monitor** in **Preferences**.
   - Reboot Ubuntu (`sudo reboot`). After login, open ModemDeck and verify `CurrentBands` and lock status are automatically restored.
5. **SamanTel SIM Swap & Operator Comparison**:
   - Power off / swap to **SamanTel** SIM, boot Ubuntu, and run **Analyzer** → **Speed Test** (bound to `wwan0` / `wwp*`).
   - Check **Operator Comparison** to verify both Irancell and SamanTel benchmarks remain saved independently.
